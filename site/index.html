AI Team OS · v1.0.1

Agent Collaboration Workbench

一个真正面向 Agent 团队协作的工作平台，把项目、任务、交付物、模型治理、 SOUL / SOP、长期记忆、审计与运行状态放进统一的控制中心。

Platform Project + Agent + Runtime

Integration OpenClaw Workspace
Release GitHub Pages + Render Ready

为什么它有意义

它不是再做一个聊天窗口，而是在探索企业如何真正管理一支 Agent 团队。平台强调的是 可观测、可治理、可追踪、可确认，而不是黑盒自动化。

核心能力

  • 项目组合、项目作战室与团队工作区
  • Agent 指挥页、模型切换、执行模式治理
  • SOUL / SOP 编辑、长期记忆和 Token 上限管理
  • OpenClaw 项目、任务、会话、文档与状态联动
  • 系统健康、平台就绪度、审计日志与发布检查

正式部署

仓库已经补齐 Docker、Render Blueprint、GitHub Actions 和 Pages 站点配置。 如果你希望完整工作台长期在线，还需要部署后端服务并为数据库与 OpenClaw 工作区提供持久化目录。
