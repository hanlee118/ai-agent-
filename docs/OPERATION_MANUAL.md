# OpenClaw Agent 协作工作台操作手册

## 1. 登录

- 打开工作台公网地址。
- 输入管理员密码登录。
- 登录后默认进入总控首页。

## 2. 首页怎么用

首页现在按 SaaS 工作台方式分为几个模块入口：

- 总控首页：看系统总览、模块入口、演示项目、重点任务。
- 团队工作区：看真实 OpenClaw 项目、交付物、任务、团队状态。
- Agent 工作台：看 Agent 当前任务、会话、最近消息，并编辑 SOUL / SOP。
- 系统运营：看运行配置、健康状态、审计记录。

## 3. 演示项目怎么验收

当前推荐验收项目：

- `test SaaS管理工作台演示`
- 工作区目录：`~/.openclaw/workspace/test-saas-demo-20260325`

建议验收顺序：

1. 进入总控首页，确认首页模块卡与演示项目卡已出现。
2. 点击“进入团队工作区”。
3. 在团队工作区确认系统默认聚焦到 `test` 演示项目。
4. 检查项目摘要、任务状态、参与 Agent、项目报告。
5. 检查交付物文档区是否展示：
   - `README.md`
   - `requirements.md`
   - `prototype.md`
   - `architecture.md`
   - `demo.html`
   - `TEST-REPORT.md`
6. 检查 `rd_manager` 当前任务是否处于进行中或接近完成状态。

## 4. 团队工作区怎么用

团队工作区主要分三块：

- 项目组合：查看所有真实 OpenClaw 项目。
- 项目作战室：查看某个项目的任务、交付物、报告、批量催办。
- Agent 面板：查看 Agent 画像、任务、会话、SOUL / SOP。

常见操作：

- 查看项目详情：左侧选项目。
- 批量回写任务：在项目作战室里勾选任务后批量修改状态/进度。
- 项目群发催办：给当前项目相关 Agent 发送统一指令。
- 查看真实交付物：在“交付物与文档”区域查看项目目录中的真实文件。

## 5. Agent 工作台怎么用

在 Agent 工作台可以：

- 看 Agent 当前任务
- 看最近会话
- 看最近消息
- 直接给 Agent 发指令
- 编辑 SOUL
- 编辑 SOP

推荐重点查看：

- `jeremy`：设计总监
- `rd_manager`：研发经理
- `qa_engineer`：测试工程师

## 6. 系统运营怎么用

系统运营页用于管理：

- 当前运行模式
- 模型配置
- API Base URL
- API Key
- 健康检查
- 发布前检查
- 审计日志

如果只是验收产品能力，不建议先改运行配置，先看现有项目与团队联动是否正常。
