# Agent 协作平台产品说明文档（最新）

> 版本：v1.2  
> 日期：2026-04-02  
> 产品名：Agent Collaboration Workbench（Agent 协作工作台）

## 1. 产品定位

这是一个面向真实项目交付的多 Agent 协作平台，不是聊天窗口。  
平台核心是把“项目推进、角色执行、质量门禁、外部协同、验收报告”串成可运营闭环。

## 2. 相比 3 月 30 日版本的关键升级

1. `advance` 推进链路增加退避恢复，降低 `IN_PROGRESS` 风暴。  
2. 真实模型门禁从软约束升级为硬门禁。  
3. 增加 ROLE_PM 执行证据门禁与关键角色白名单门禁。  
4. `REAL_MODEL_GATE_FAILED` 支持动作链修复，而非单一动作。  
5. GitLab Harness 打通同步与回写，支持完成自动关单。  
6. 健康检查支持真实模型自检与一键修复指引。  
7. 增加可重复验收脚本，支持固定路径复验。

## 3. 目标用户

- 项目负责人 / PMO
- 产品、设计、研发、测试协作团队
- 平台运维与治理负责人

## 4. 当前平台工作流

1. 自然语言创建项目并解析。
2. 系统按阶段驱动多角色执行。
3. 交付物提交后进入审批。
4. 执行质量门禁（真实模型 + 角色证据 + 白名单命中）。
5. 门禁失败返回 `requiredActions + recoveryPlan`。
6. 执行动作链修复后重新审批。
7. DEV/ACCEPT 同步 GitLab Harness 并回写状态。
8. 输出验收与健康报告，进入可追溯闭环。

## 5. 成果验收入口

- 前端入口：`http://127.0.0.1:5173`
- 健康接口：`http://127.0.0.1:8787/health`
- OpenAPI：`http://127.0.0.1:8787/api/docs.json`
- `apps/web/public/generated/*.html` 与 `4173` 一类静态服务，仅用于查看已生成交付物，不作为实时项目状态判断依据。
