> **版本**: v1.0  
> **日期**: 2026-03-27  
> **产品名称**: Aegis OS (OpenClaw Collaboration System)  
> **产品定位**: AI 协作工作台

---

## 1. 产品概述

### 1.1 产品愿景

Aegis OS 是一个**AI Agent 协作工作台**，让用户通过自然语言描述需求，AI Agent 团队自动分解任务、执行开发、监控进度、申请审批，用户全程可视化掌控。

**核心理念**: "你说需求，Agent 自动推进，你全程看得见、随时停得下。"

### 1.2 目标用户

| 用户角色 | 使用场景 |
|---------|---------|
| **产品经理** | 创建项目、管理需求、审批阶段交付物 |
| **研发工程师** | 查看任务分配、监控系统健康、干预异常 |
| **架构师** | 配置 Agent 能力、规划团队拓扑 |
| **项目经理** | 监控项目进度、协调多 Agent 协作 |
| **运维/系统管理员** | 管理 AI 模型接入、监控系统性能 |

### 1.3 核心价值

| 价值点 | 说明 |
|-------|------|
| **自动化** | 自然语言需求自动转化为正式项目 |
| **可视化** | 实时观测 Agent 工作状态和项目进度 |
| **可控性** | 阶段审批机制确保关键节点人工确认 |
| **协作性** | 多 Agent 分工协作，拓扑图清晰展示关系 |

## 2. 功能架构

### 2.1 模块总览

```
┌─────────────────────────────────────────────────────────────┐
│                      Aegis OS                               │
├─────────────┬─────────────┬─────────────┬─────────────────┤
│   Dashboard  │ Model Nexus │   Projects  │    Agents       │
│   (工作台)    │  (模型中心)  │   (项目组合) │    (Agent工作室) │
├─────────────┴─────────────┴─────────────┴─────────────────┤
│                    Decision Center (决策中心)                │
├─────────────────────────────────────────────────────────────┤
│         团队拓扑图 │ 通知中心 │ 审计日志 │ 系统设置           │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 功能模块详情

#### 2.2.1 Dashboard (工作台)

**用途**: 系统首页，展示全局状态和快速入口

**功能要素**:
- **系统状态卡片**: 活跃项目数、Agent 负载、待处理决策、每日成本
- **快捷入口**: 跳转各模块的快速链接
- **决策中心入口**: 需要人工处理的决策事项
- **实时刷新**: 每 12 秒自动刷新数据

#### 2.2.2 Model Nexus (模型中心)

**用途**: 管理 AI 计算模型（LLM）的接入和监控

**功能要素**:
- **模型列表**: 展示所有已接入模型
  - 名称、提供商、状态 (Healthy/Degraded/Offline)
  - 总 Token 消耗、每日 Token 消耗
  - 当前任务、延迟、吞吐
- **接入新模型**: 
  - 填写模型名称、提供商
  - 配置 API Base URL
  - 设置 Token 限额
- **模型详情**:
  - 实时日志 (bash/json/assistant/system)
  - 使用量图表 (Pie/Bar/Area Charts)
  - 性能指标监控

#### 2.2.3 Agents (Agent 工作室)

**用途**: 管理 AI Agent 配置和监控状态

**功能要素**:
- **Agent 列表**: 
  - 名称、角色、状态 (Idle/Thinking/Executing/Offline)
  - 负载率、当前任务数、Session 数
  - Token 使用量/限额
- **Agent 配置**:
  - SOUL 编辑: Agent 的身份定义和行为原则
  - SOP 编辑: Agent 的标准操作步骤
  - 当前使用模型切换
- **部署新 Agent**: 创建新的 Agent 实例
- **团队拓扑图**: 可视化 Agent 之间的关系和依赖

#### 2.2.4 Projects (项目组合)

**用途**: 管理所有项目，了解整体Portfolio

**功能要素**:
- **项目列表**:
  - 项目名称、描述、状态 (Planning/Development/Testing/Completed/Blocked)
  - 当前阶段、进度百分比
  - 负责人、参与 Agent
- **项目详情**:
  - 阶段进度 (INIT → ANALYSIS → DESIGN → DEV → ACCEPT)
  - 交付物管理 (草稿/提交/审批通过/驳回)
  - 时间线事件
- **创建新项目**: 通过自然语言描述自动解析为正式项目

#### 2.2.5 Decision Center (决策中心)

**用途**: 集中处理需要人工确认的关键决策

**功能要素**:
- **待决策列表**: 需要人工审批的事项
- **决策操作**: 批准/驳回/要求返工
- **历史决策**: 已完成的决策记录

#### 2.2.6 团队拓扑图

**用途**: 可视化 Agent 团队结构和协作关系

**功能**: 
- 节点表示 Agent
- 连线表示协作关系
- 状态颜色区分 (在线/离线/忙碌)

#### 2.2.7 通知中心

**用途**: 统一管理所有系统通知

**功能**:
- 按严重程度分类 (critical/warning/info)
- 标记已读/未读
- 处理工作流 (open/acknowledged/resolved)

#### 2.2.8 审计日志

**用途**: 记录所有关键操作，支持追溯

**记录内容**:
- 操作人、操作时间、操作类型
- 操作详情、前后状态变化

#### 2.2.9 系统设置

**用途**: 系统级配置管理

**功能**:
- 运行时设置
- 健康检查
- 诊断工具

## 3. 用户旅程

### 3.1 创建项目流程

```
1. 用户在 Dashboard 输入自然语言需求
2. 系统解析需求，生成项目结构
3. 自动分配 Agent 角色
4. Agent 开始执行任务
5. 到达阶段节点 → 暂停等待审批
6. 用户审批通过 → 继续执行
7. 用户驳回 → 返回修改
8. 项目完成 → 归档
```

### 3.2 监控流程

```
1. 用户打开 Dashboard
2. 查看系统状态卡片
3. 点击异常指标 → 进入详情
4. 查看 Agent 实时日志
5. 如有异常 → 干预或终止任务
```

## 4. 技术架构

### 4.1 系统架构

```
┌──────────────────┐     ┌──────────────────┐
│   Frontend (Web)  │────▶│   Backend (API)   │
│   React + Vite   │     │   Express + Prisma│
│   Tailwind CSS   │     │   SQLite DB       │
└──────────────────┘     └──────────────────┘
         │                        │
         │   SSE (实时推送)        │
         ▼                        ▼
┌──────────────────┐     ┌──────────────────┐
│  OpenClaw Engine │     │  AI Models (LLM)  │
│  (本地 Agent)     │     │  GPT-4/Claude/etc │
└──────────────────┘     └──────────────────┘
```

### 4.2 数据库模型

| 模型 | 说明 |
|-----|------|
| **Project** | 项目信息、状态、进度 |
| **Task** | 任务、分配、状态 |
| **Stage** | 项目阶段 (INIT/ANALYSIS/DESIGN/DEV/ACCEPT) |
| **Deliverable** | 交付物、审批状态 |
| **AgentProfile** | Agent 配置、SOUL、SOP |
| **Model** | AI 模型配置 |
| **ModelLog** | 模型执行日志 |
| **AuthSession** | 认证会话 |
| **AuditLog** | 审计日志 |
| **NotificationState** | 通知状态 |

### 4.3 API 端点

| 端点 | 说明 |
|-----|------|
| `GET /api/projects` | 获取项目列表 |
| `POST /api/projects` | 创建项目 |
| `GET /api/models` | 获取模型列表 |
| `POST /api/models` | 创建模型 |
| `GET /api/agents` | 获取 Agent 列表 |
| `PATCH /api/agents/:id/soul` | 更新 Agent SOUL |
| `GET /api/team/topology` | 获取团队拓扑 |
| `GET /api/tasks` | 获取任务列表 |
| `GET /api/notifications` | 获取通知 |
| `GET /api/audit-logs` | 获取审计日志 |
