# 用户操作指南

## 创建项目

1. 先通过 `New Project Issue` 提交需求。
2. 等待需求确认（Issue 状态为 confirmed）。
3. 在项目列表中创建项目并关联对应需求。

## Issue-First 门禁说明

- 当返回 `LOCAL_ISSUE_REQUIRED` 时，表示当前项目未完成需求 Issue 绑定。
- 需要先补齐 Issue 并确认，再继续项目创建或推进。

## 角色说明（当前平台）

- `Viewer`：查看项目、任务与交付物。
- `Editor`：更新任务、提交阶段内容。
- `Owner`：负责项目推进与关键决策。
- `Admin`：系统初始化、治理配置与审计管理。
