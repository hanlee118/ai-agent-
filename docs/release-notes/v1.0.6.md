# v1.0.6 发布说明（2026-04-17）

## 本次修复
- 修复“项目创建后预备阶段”门禁语义错误：`执行创建后需求预备` 现在只生成草案，不再自动放行正式项目详情页。
- 修复预备阶段缺少可审阅内容的问题：新增多 Agent 讨论结论、项目理解草案、回填输入三类内容的结构化回显。
- 修复预备阶段缺少人工确认步骤的问题：新增“用户确认预备内容”硬门禁，未确认前无法进入正式执行页。
- 修复预备阶段流程文案误导问题：时间线事件调整为“草案已生成，待用户确认后放行”。

## 本次优化
- 新增预备阶段接口能力：
  - `POST /api/projects/:id/post-create-prep/draft`：保存预备草案（讨论结论 / 分析草案 / 回填输入）。
  - `POST /api/projects/:id/post-create-prep/confirm`：确认预备草案并解锁正式项目页。
- 预备阶段状态返回 `draft` 详情，前端可直接回显与编辑。
- 预备阶段专属页面升级为可交互工作台：
  - 支持内容编辑
  - 支持保存草案
  - 支持确认通过后进入正式详情

## 兼容性说明
- `complete` 项目会严格执行“预备草案 + 用户确认”双门禁。
- 已有项目若缺少预备确认信息，会被自动拦截到预备阶段页，确认后可继续。
