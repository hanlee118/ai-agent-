# v1.0.3 发布说明（2026-04-04）

## 本次修复
- 修复 OpenClaw `agent --json` 在 stdout / stderr 混合噪音下的 JSON 解析脆弱问题，改为从混合输出中提取最后一个有效 JSON 对象。
- 修复 `INIT` 阶段审批门禁错误要求技能证据的问题，避免立项阶段被误拦截。
- 修复审批输出协作字段缺失时无法从当前 `liveSession` / 当前阶段交付物回填协作证据的问题。

## 本次优化
- 阶段执行卡只显示当前阶段更相关的角色按钮，减少无效派工入口。
- 为研发 / QA 增加轻量派工摘要：
  - 自动附带当前失败执行或最近执行摘要
  - 自动附带当前缺口摘要
  - 支持 `仅阻断项 / 全部缺口`
  - 支持 `纯文本 / Markdown`
- 阶段卡页面直接展示轻量派工摘要预览，复制结果与当前视图保持一致。

## 数据清理
- 清理本地推荐测试 / 复测项目 7 个。
- 清空 `apps/web/public/generated` 下历史静态生成页 12 个，避免旧 demo 干扰真实交付判断。

## 验证
- `pnpm exec tsx --test src/openclaw/workspace.test.ts` 通过（11/11）
- `pnpm --filter @occ/api typecheck` 通过
- `pnpm --filter @occ/web typecheck` 通过
- `OCC-20260404-001` 本地审批复跑通过，项目已从 `INIT` 推进到 `ANALYSIS`
- `pnpm release:local` 已作为本次本地发布门槛执行

## 版本说明
- 这是一次补丁版本发布，不引入新的产品主线，重点是把“真实执行、真实门禁、真实派工”补到更可交付的状态。
