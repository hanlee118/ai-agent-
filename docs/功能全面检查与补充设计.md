## 二、补充设计详情

### A. 优化策略按钮 - 完整交互设计

**位置**：Dashboard 中的 `onOpenDecisionCenter`

**当前问题**：点击后无明确反馈，用户不知道发生了什么

**完整交互设计**：

```
用户点击"优化策略"
    ↓
显示加载遮罩 + "正在分析..."
    ↓
调用 API 获取实时数据
    ↓
展示"优化策略面板"（右侧滑出或全屏Modal）
┌─────────────────────────────────────────────────────┐
│ 📊 智能优化策略                              [X 关闭] │
├─────────────────────────────────────────────────────┤
│                                                     │
│ 【Agent负载分析】                                    │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 🔴 平头舅舅  负载 92%  [建议分流]              │ │
│ │ 🟡 平头叔   负载 65%  [正常]                   │ │
│ │ 🟢 平头哥   负载 30%  [空闲]                   │ │
│ │ 🟢 平头姑   负载 10%  [空闲]                   │ │
│ └─────────────────────────────────────────────────┘ │
│                                                     │
│ 【项目阻塞分析】                                     │
│ ┌─────────────────────────────────────────────────┐ │
│ │ ⚠️ SaaS管理台  等待平头叔 PRD文档  [催办]      │ │
│ │ ⚠️ OpenClaw核心  等待平头舅舅 技术方案  [催办] │ │
│ └─────────────────────────────────────────────────┘ │
│                                                     │
│ 【建议操作】                                         │
│ ┌─────────────────────────────────────────────────┐ │
│ │ ○ 分流任务：从平头舅舅 分流 2个任务到平头姑     │ │
│ │ ● 调整优先级：将 OpenClaw 设为高优先级         │ │
│ │ ○ 提醒负责人：一键发送催促消息                  │ │
│ └─────────────────────────────────────────────────┘ │
│                                                     │
│              [应用建议]  [取消]                    │
└─────────────────────────────────────────────────────┘
```

**技术实现**：
- 数据来源：`/api/openclaw/agents` + `/api/openclaw/projects`
- 前端计算负载阈值（>80% 高负载，<30% 空闲）
- 阻塞检测：项目状态 + 依赖关系

### B. AgentCommander 确认卡片 - 完整交互设计

**位置**：AgentCommander 的发送按钮

**当前问题**：用户输入指令后直接发送，无确认流程

**完整交互设计**：

```
用户输入指令："为用户管理系统创建PRD"
    ↓
点击"发送"
    ↓
显示加载状态："AI正在理解指令..."
    ↓
展示"理解确认卡片"（Modal）
┌─────────────────────────────────────────────────────┐
│ 🤔 确认AI理解                                   [X] │
├─────────────────────────────────────────────────────┤
│                                                     │
│ 我理解你要：                                        │
│                                                     │
│ 为"用户管理系统"项目创建产品需求文档（PRD）          │
│                                                     │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 📋 文档类型：PRD                               │ │
│ │ 👤 负责人：平头叔（需求分析师）                 │ │
│ │ ⏱️ 预计完成：2小时                             │ │
│ │ 📎 关联项目：用户管理系统（新建）               │ │
│ └─────────────────────────────────────────────────┘ │
│                                                     │
│ 请确认AI的理解是否正确：                            │
│                                                     │
│    [✅ 确认执行]   [✏️ 修改指令]   [❌ 取消]      │
└─────────────────────────────────────────────────────┘
```

**技术实现**：
- 前端解析指令关键词（项目名、动作、涉及角色）
- 动态从 API 获取匹配的 Agent
- 用户确认后才真正调用 `/api/openclaw/agents/:id/message`

### C. 新建项目预览确认 - 完整交互设计

**位置**：NewProjectModal

**当前问题**：输入自然语言后直接创建，无预览确认

**完整交互设计**：

```
用户输入："做一个用户管理系统，包含登录注册、个人资料"
    ↓
点击"创建"或按回车
    ↓
显示加载："正在解析..."
    ↓
展示"解析预览"（Modal）
┌─────────────────────────────────────────────────────┐
│ 📋 项目预览                                  [X 关闭] │
├─────────────────────────────────────────────────────┤
│                                                     │
│ 项目名称：用户管理系统                               │
│ 描述：用户登录、注册、个人资料管理                    │
│                                                     │
│ 【识别到的任务】                                     │
│ ┌─────────────────────────────────────────────────┐ │
│ │ ☑️ 用户登录功能   - 平头舅舅                    │ │
│ │ ☑️ 用户注册功能   - 平头舅舅                    │ │
│ │ ☑️ 个人资料页面   - 平头舅舅                    │ │
│ │ ☐️ 权限管理       - 平头舅舅                    │ │
│ └─────────────────────────────────────────────────┘ │
│                                                     │
│ 【建议的Agent团队】                                  │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 👤 平头叔  需求分析   [已选]                   │ │
│ │ 👤 平头伯  产品规划   [已选]                   │ │
│ │ 👤 平头舅舅  研发     [已选]                   │ │
│ │ 👤 平头姑  测试       [已选]                   │ │
│ └─────────────────────────────────────────────────┘ │
│                                                     │
│      [确认创建]   [编辑项目信息]   [取消]          │
└─────────────────────────────────────────────────────┘
```

**技术实现**：
- 调用 `POST /api/projects/parse` 解析自然语言
- 调用 `GET /api/openclaw/agents` 获取可选 Agent
- 用户确认后调用 `POST /api/projects` 创建
