# Agent 协作工作台 v1.0.0 产品说明文档

## 1. 文档信息

- 产品名称：Agent 协作工作台
- 版本号：v1.0.0
- 文档日期：2026-03-26
- 文档定位：面向验收、交付、运营与后续迭代的正式产品说明
- 当前形态：本地可部署、可登录、可调用真实 OpenClaw 工作区的 Agent 团队协作平台

## 2. 产品定义

Agent 协作工作台是一个围绕“项目 + Agent + 任务 + 运行治理”构建的 AI 团队协作平台。它不是单纯的聊天界面，也不是只展示状态的看板，而是一个可以让用户真正管理 Agent 团队、追踪项目执行、控制运行策略、沉淀长期记忆并进行审计追踪的工作台。

v1.0.0 的核心目标已经落地为一个可运行、可服务、可监控、可验收的单管理员版本，支持真实 OpenClaw 工作区联动，而不是只依赖演示数据。

## 3. 产品价值

- 让用户像管理真实团队一样管理 Agent 团队
- 让项目状态、任务分配、交付物和系统健康都可视化
- 让每个 Agent 的模型、SOUL、SOP、执行策略和 Token 限额可治理
- 让关键执行动作可确认、可回溯、可审计
- 让平台既能本地生产部署，也能继续向组织化版本扩展

## 4. v1.0.0 已实现能力

### 4.1 平台基础

- 支持首次管理员初始化与登录鉴权
- 支持前后端一体化本地部署
- 支持中文 / 英文双语切换
- 支持桌面端优先的 SaaS 工作台布局，并兼容移动端基础访问

### 4.2 项目协作

- 支持自然语言需求预解析与理解确认
- 支持创建项目、查看项目组合和项目作战室
- 支持查看阶段、任务、交付物、时间线与实时输出流
- 支持项目审批、驳回、阶段提交、人工介入、恢复推进

### 4.3 OpenClaw 联动

- 支持读取真实 `~/.openclaw` 工作区中的项目、任务、文档、会话与最近消息
- 支持展示 OpenClaw 项目进展、阻塞项、参与 Agent 和项目报告
- 支持回写单任务与批量任务更新
- 支持从平台创建新的 OpenClaw Agent 并写入工作区配置

### 4.4 Agent 指挥与治理

- 支持 Agent 列表页与单 Agent 指挥页
- 支持单独为 Agent 切换模型、默认模型与回退模型
- 支持 `confirm_first` 与 `autonomous` 两种执行模式
- 支持先生成理解确认卡，再由用户确认执行
- 支持给单个 Agent 或多个 Agent 下发任务
- 支持修改 Agent 的介绍、职责、协作白名单和工具白名单
- 支持编辑 Agent 的 `SOUL` 与 `SOP`
- 支持记录 Agent 长期记忆、调用日志与当日 Token 使用摘要
- 支持为 Agent 设置单次输入、单次输出与每日 Token 上限

### 4.5 系统运营

- 支持查看运行模式、模型配置与连通性校验
- 支持查看系统健康状态和发布前就绪度检查
- 支持审计日志查看
- 支持请求级 `x-request-id` 跟踪

## 5. 平台模块

- 总控首页：模块入口、关键项目、重点任务、运行概览
- 项目组合：查看平台项目与真实 OpenClaw 项目
- 项目作战室：阶段推进、审批、任务、交付物、时间线、实时流
- 团队工作区：聚焦 OpenClaw 项目、任务、文档与协作状态
- Agent 工作台：查看 Agent 画像、负载、当前任务、会话与能力摘要
- Agent 指挥页：模型切换、理解确认、任务下达、SOUL/SOP 编辑、记忆与用量治理
- 系统运营：运行配置、健康检查、就绪度检查
- 审计轨迹：关键操作和配置变更追踪
- 设置：语言和基础偏好配置

## 6. 典型使用流程

### 6.1 创建新项目

1. 管理员登录平台。
2. 在首页或项目页输入需求描述。
3. 系统生成需求理解结果与建议团队。
4. 用户确认后创建项目。
5. 在项目作战室持续跟踪阶段、任务、交付物和审批节点。

### 6.2 指挥单个 Agent

1. 进入 Agent 列表，选择具体 Agent。
2. 在 Agent 指挥页切换模型与执行模式。
3. 输入任务指令并生成理解确认卡。
4. 用户确认后执行，或开启自主执行模式持续运行。
5. 查看 Agent 回复、任务变化、长期记忆与用量记录。

### 6.3 管理真实 OpenClaw 团队

1. 打开团队工作区。
2. 查看真实 OpenClaw 项目和当前进度。
3. 查看每个 Agent 当前任务、会话和最近消息。
4. 按项目或批量方式回写任务状态。
5. 通过 Agent 指挥页持续调整模型、SOUL、SOP 与治理策略。

## 7. 当前部署形态

- 前端：React + Vite 构建后的静态资源
- 后端：Express API
- 数据库：Prisma + SQLite
- 运行模式：`scripted` 与 `openai-compatible`
- 真实集成：OpenClaw 本地工作区
- 推荐端口：`http://localhost:8787`

## 8. 适用场景

- AI 产品团队项目推进
- 多 Agent 协作编排与监督
- 本地私有化部署的 Agent 工作平台
- Agent 团队运营、测试、验收与演示

## 9. 当前版本边界

v1.0.0 已经是可运行的闭环版本，但仍然保留明确边界：

- 当前为单管理员模式，未引入多用户权限体系
- 数据库使用 SQLite，适合单机部署与中小规模运行
- GitHub、IM、工单系统等外部平台尚未形成正式双向集成
- Cloudflare Quick Tunnel 只适合临时公网验收，不作为正式生产域名方案

## 10. 交付结论

v1.0.0 已经完成从“概念工作台”向“真实可用工作台”的转换。它具备项目协作、Agent 指挥、OpenClaw 工作区联动、系统治理、审计追踪和本地发布能力，可以作为后续 1.x 版本持续演进的稳定基础。
