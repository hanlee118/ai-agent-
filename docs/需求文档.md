# Agent 协作平台需求文档（最新）

> 版本：v1.1  
> 日期：2026-04-01  
> 适用仓库：`/private/tmp/ai-agent-check`

## 1. 文档说明

本文档是中文需求入口，和 [LATEST_REQUIREMENTS_SPEC.md](./LATEST_REQUIREMENTS_SPEC.md) 保持一致。  
若两者冲突，以 `LATEST_REQUIREMENTS_SPEC.md` 为准。

## 2. 本版本需求目标

- 建立可收敛的多 Agent 阶段推进流程。
- 建立真实模型强门禁，禁止 scripted/degraded 假通过。
- 建立角色级质量门禁（ROLE_PM + ROLE_DESIGN/ARCH/DEV/QA）。
- 建立 GitLab Harness 外部协同闭环。
- 建立可重复验收与一键健康检查体系。

## 3. 核心需求清单（Must Have）

1. 项目推进必须支持风暴检测、退避与软恢复。  
2. 审批阶段必须执行真实模型门禁。  
3. 门禁失败必须返回可执行的 `requiredActions + recoveryPlan`。  
4. DEV/ACCEPT 阶段必须支持 GitLab issue 同步与 webhook 回写。  
5. 平台必须输出结构化验收与健康报告到 `docs/reports/`。  
6. 必须提供可重复通过的固定验收脚本路径（OCC-20260401-018）。

## 4. 验收命令

```bash
pnpm --filter @occ/api typecheck
pnpm --filter @occ/api test:routes
pnpm test:smoke
pnpm health:check
pnpm verify:repeatable:018
```

## 5. 真实模型门禁前提

```bash
MODEL_PROVIDER=openai-compatible
MODEL_API_BASE_URL=<your_base_url>
MODEL_API_KEY=<your_api_key>
MODEL_NAME=<your_model>
ENFORCE_REAL_MODEL_GATE=true
```
